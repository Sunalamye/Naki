## 摘要
三麻終於有本地推論，拔北與三人友人房都修好了；畫面依 SwiftUI 審查做了一輪無障礙與排版修正。

## 變更

### 新功能
- 三麻有本地推論：MortalSwift 0.6.0 新增 `AkagiSanma`，把 Akagi v3 的三麻行為克隆模型（Apache 2.0）移植成純 Swift，零 Rust 依賴；雲端推論開著時仍以雲端為準，退化或關閉時由本地接手，側欄標「Akagi 三麻・default strength」
- 三麻本地引擎的合法動作由伺服器 oplist 授權，模型只在授權範圍內挑；三局 live（友人房＋人機）驗過立直、自摸、榮和、碰、拔北整條鏈
- `POST /debug/ui` 可直接開進階設定／插件頁／日誌面板／全自動表並切語言，`GET /debug/ui` 查狀態（只在 DEBUG build）
- `scripts/mutate.py`：對 git diff 範圍做手工變異測試；2026-09-30 審查以來的 48 個改動檔跑過，補 52 條測試（734 → 853）

### 修正
- 拔北：剛摸到的北（含嶺上、立直後）拔北時伺服器從不執行、60 秒後被判離開；請求補 `moqie=true` 後 live 11 次拔北 11 次成功；回音等待 0.7 → 1.5 秒避免重複送出
- 被擠下線後自動打牌不再每秒重送：斷線立刻停手並顯示停滯，之後 2 → 30 秒退避
- 三人友人房：`room_quick_test`／`room_create` 原本帶四麻細則（赤寶 3、起點 25000）被伺服器回 error 1112；三人房改預設三麻規則（赤寶 2、起點 35000、返點 40000），`mode` 依人數對應（三人東 11／三人南 12）
- 埠號顯示 `8765`（原本被格式化成「8,765」，連可複製的 curl 都壞）
- 日誌面板滿 5000 筆後自動捲動失效；時間戳與分類折行；搜尋框用語「搜索」改「搜尋…」
- 工具列的延遲 stepper 箭頭與「秒」擠在一起、MCP／WebSocket 膠囊兩行錯位
- `liqi.json` 補 `ReqSelfOperation.auto_operation`（雀魂 4.0.47）；雲端 react 逾時 2 → 3 秒

### 行為變更
- 局間確認與續局改看「目前引擎支援三麻」，不再寫死雲端
- iOS 側欄按鈕與叫回鈕改為 44pt 點擊區（控制列變高）；模型選單、匯入預覽的開關與欄位都有 VoiceOver 名稱；「減少動態」時改淡入淡出；不以顏色區分時狀態點畫符號
- macOS 決策面板可拖寬（300–480）；區服選擇與全自動設定表可捲動；雲端到期時間改隨系統 locale 格式；插件頁 log 改「時:分:秒.毫秒 訊息」
- 設定頁與插件頁的網路探測、全自動啟動、區服選擇收進 Action 層，View 只顯示結果
- 四語字串目錄補齊新文案（機器翻譯，未經母語校對）

## 已知限制
- 被擠下線後的退避與停滯顯示只有單測，live 沒遇到樣本
- 親家局首第一打偶發「伺服器受理卻無回音、0.7 秒後重送才打出」，原因未明
- iOS 只驗了模擬器 build，實機未測；iOS 控制列改 44pt 會壓縮橫向的決策區
- 三麻本地引擎沒有役判定，和牌與否完全交給伺服器；九種九牌仍未 live 驗證
- 三麻本地引擎強度為 default strength，非 Mortal 等級
- `Naki-M.ipa` 未簽名，需用 AltStore／Sideloadly 自行簽名側載；macOS 版未公證，首次開啟要在系統設定放行
