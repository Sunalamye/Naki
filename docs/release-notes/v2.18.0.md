## 摘要
側欄與設定頁的間距、外框與狀態色統一，數值改成滾動顯示，動畫全部尊重「減少動態效果」。插件可以自帶設定頁；自動打牌修正「過」送不出去時的誤判與重送、四麻九種九牌被改打牌等問題。

## 變更
### 新功能
- 設定改版：Mac 的設定改為獨立視窗，分「一般」「連線」「AI」「開發者」四個分頁，主視窗工具列的齒輪開啟；iPhone 為單頁捲動的四段，「開發者」預設折疊。雲端推論拆成 AI 頁的「雲端推論」與開發者頁的「雲端 API」，兩頁都會顯示雲端是否生效；缺哪一項時直接點名（例如「「啟用雲端推論」開關」）。連線頁的 User-Agent 欄位滑鼠停留可看完整值。設定值與預設值不變
- 插件可以自帶設定頁：插件在 manifest 宣告 `settingsUI`，插件頁會在該插件下方載入它自己的設定畫面；值仍由 Naki 保管
- 插件可改寫送出的請求（`rewriteSend`）：屬最高權限級，必須先開啟「允許插件改動送出」總開關（預設關閉），登入、對局與付費相關請求一律不可改
- 延遲 Stepper 到最小值顯示「最快」、最大值顯示「最慢」，VoiceOver 也會念出
- 側欄異常列（雲端失敗、自動打牌停滯、三麻提示）出現與消失有淡入與上移動畫

### 修正
- 安全：Debug server 現在會拒絕來自本機其他 port 網頁的請求（帶 Origin 且 port 與實際綁定 port 不符回 403）；curl 與 MCP client 不送 Origin，不受影響
- 自動打牌「過」連續送不出去時，不再被當成成功；停滯提示會正常出現
- 被擠下線時，「過」不再每拍無限重送，改為逐輪退避（2 秒起，上限 30 秒）
- 四麻本地模型選擇九種九牌時，自動模式不再改送打牌
- 自動確認在切換到「推薦」模式期間，不再記錄沒發生的重送、提早放棄
- 段位場排隊中重載頁面、或排隊請求被拒後改開友人房時，人數不再寫錯到段位場，全自動續局不會排錯場次
- 推薦顯示關閉時，狀態列不再顯示「N 推薦」
- 開啟系統「減少動態效果」時，Log 面板捲動與 iOS 面板開合不再有動畫
- MCP：`bot_sync` 失敗時的回傳符合宣告格式；`replay_game` 決策數剛好等於上限時不再誤報截斷；狀態資訊對日誌保留規則的說明改正；帳號與段位場 ID 的來源標記與實際採用的值一致

### 行為變更
- 插件移除改為原地確認，確認狀態綁定插件；移除後清單直接合攏
- 介面文案改用使用者語言，去掉內部術語
- 摘要列與四家點數改用滾動數字，不會短暫顯示不存在的值
- 側欄與決策卡的間距略寬、外框變淡，狀態色（紅／橙／綠／藍）語意統一：紅＝會讓 Naki 失效、橙＝本局受影響或資料外送、綠＝可用、藍＝一般提示
- 橫幅第三行說明文字稍淡
- 內部：畫面數值收進單一定義點；新增元件快照基準、像素比對與四語系字串目錄檢查；程式碼審查重構（行為不變），詳見 `docs/archive/audit/intention-revealing-2026-10-14.md`

## 已知限制
- 設定改版的 UI 測試（macOS 與 iOS）只確認能編譯，沒有執行；macOS 因 Automation Mode 需要用戶授權而無法跑
- 設定視窗只看過深色模式，淺色模式未看
- iOS 設定畫面在最後一次改碼（GroupBox 撐滿寬度）之後沒有截圖，也沒有重跑 UI 測試
- README 的設定截圖仍是改版前的圖，待補分頁新圖
- 插件自帶設定頁沒有在 App 內實機手測，iOS 17–25 只確認能編譯
- 插件改寫送出請求沒有在伺服器上實測；改寫後遊戲如何解讀回應由插件作者負責
- 九種九牌、被擠下線的退避、段位場被拒等修正沒有 live 對局驗證
- 被擠下線時，「過」在當輪仍會先重試數次才開始退避
- 工具列延遲 Stepper 到端點時會多兩個字，工具列會變寬；實機未看
- 「減少動態效果」的實機觀感未錄影驗證
- 新的四語系「最快」「最慢」字串在畫面上的樣子未逐語系確認
- 未簽名：首次開啟要在系統設定放行；IPA 需自行簽名側載
