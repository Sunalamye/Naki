## 摘要
設定頁新增雀魂連線的 User-Agent 與 header 自訂，雲端伺服器 URL 不再接受雀魂網域；暗槓與加槓並存時送錯槓種類的問題與雲端錯誤提示一併修正，README 補上封號案例與日文版。

## 變更

### 新功能
- 設定頁新增「雀魂連線」區：可自訂 User-Agent 與額外 header。保留名稱與非法 header 會被擋下
  - 額外 header 只作用於主文件請求；只有 User-Agent 會套用到全部請求（含 WebSocket 握手）
  - 改完要整頁重載才生效
  - 對雀魂伺服器的實際效果未驗證
- 雲端推論的「伺服器 URL」拒絕雀魂網域（含子網域與結尾帶點的寫法）。被拒時沿用既有的「還缺…」提示顯示原因，對局狀態與 API key 不會被建立的 client 送出

### 修正
- 暗槓與加槓並存時，自動打牌一律送暗槓 type 的問題：槓種類現在從雲端與三麻建議一路帶到 resolver 與 executor，只在伺服器授權該種槓時才送出，未授權則退回打牌，不重試。本地 Mortal 行為不變
- 雲端 API 回 401／403／429 時，提示改為只陳述可觀察的狀態（伺服器拒絕這把 key、被限流並附 retryAfter）。HTML 錯誤頁不再原樣顯示；預設服務另附 `!api_new` 指引。伺服器原訊息仍接在前綴後供診斷

### 文件
- README 免責段補上封號案例，並區分「案例」「社群推測」「已確認」三種說法；新增 API key 誤送雀魂網址後的撤銷或輪替指引。文件不承諾任何設定能避免封號
- README.en.md 對齊 2.15.0 的內容
- README.md 補上 Full Auto 模式、修正 Legacy 模式敘述與安裝段
- 新增日文版 README

## 已知限制
- 加槓的 index 與 tile 仍未帶，等待 live 抓包確認協定語意
- 自訂 User-Agent 與 header 對雀魂伺服器的效果未驗證
- 伺服器 URL 的防護只擋之後的誤送；曾誤填雀魂網址的使用者仍須到原發放服務撤銷或輪替 key
- README 的版本 badge 為靜態圖片，每個版本都要手動修改
