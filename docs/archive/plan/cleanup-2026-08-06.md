## 1. MCP 工具參數落 log 前遮蔽憑證

`MCPHandler` 原本把 `tools/call` 參數原文寫進 log，`lobby_login_beat` 的
`contract`（登入憑證）因此進了 `all.log`——違反本 repo「不得提交 credential」。

**做法**：`MCPHandler.loggableArgs(_:)` 以 key 集合
（`contract`/`token`/`secret`/`password`/`apiKey`）遮蔽值、只留長度，其餘參數照舊。

**取捨**：不做 per-tool 白名單——用 key 名判斷，未來新增帶憑證參數的工具
只要命名不偏離就自動被蓋住；代價是同名的非敏感參數也會被遮（可接受，
debug 需要值時查 Keychain 或伺服器端）。回歸鎖：`MCPProtocolSpecTests` 兩個測試。
